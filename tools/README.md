# Subora SEO pages

The public pages (about, how-it-works, safety, faq, contact, terms, privacy, refunds) and the
crawlable intro inside index.html are generated by `build-pages.mjs`.

1. Fill in `tools/site.config.json` (support email, phone, WhatsApp, city, business name, social links).
   Empty fields are simply left out of the pages.
2. From the project root run: `node tools/build-pages.mjs`
3. Deploy. The script prints anything still missing.

FAQ, terms, privacy and refund text is read straight from index.html, so edit the wording there
and run the script again. Do not edit the generated .html pages by hand; the next run overwrites them.
The block between `<!--SEO-SHELL-START-->` and `<!--SEO-SHELL-END-->` in index.html is also generated.
